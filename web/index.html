Fundamentals of AI and ML

Core Concepts & Terminology

🤖
Artificial Intelligence

Building systems that perform tasks requiring human-like intelligence: perception, language understanding, reasoning, recommendation, and decision support.

🧠
Machine Learning

Behavior improves from data and experience (training) rather than hand-coded rules. A model maps inputs to outputs; an algorithm learns that mapping.

🧬
Deep Learning

Neural networks with many layers learning hierarchical representations. Powers modern computer vision, NLP, and transformer-based language models.

✨
Generative AI

Models learn to generate new content (text, images, audio, code) conditioned on prompts. Overlaps with ML and deep learning.

Inference Types

⚡
Real-time (Online)

Low-latency responses for chatbots, fraud scoring on a click.

📦
Batch Inference

Scoring large volumes asynchronously — overnight scoring of customers, bulk document processing.

Data Types

Category Examples
Labeled vs Unlabeled Labeled: spam/not spam. Unlabeled: raw text for clustering or pre-training.
Structured Rows/columns in databases (tabular).
Unstructured PDFs, images, audio, free text.
Time Series Metrics over time (demand forecasting).
Modalities Text, image, audio, video; multimodal models use more than one.

Learning Paradigms

Supervised Classification / Regression

Learn input→output from labeled examples. The model sees correct input-output pairs during training.

Example: spam detection, price prediction
Unsupervised Clustering / Dimensionality Reduction

Find structure without labels. The model discovers patterns and groupings in data on its own.

Example: customer segmentation, anomaly detection
Reinforcement Games / Robotics / Control

Learn via rewards/penalties from an environment. The model learns which actions maximize cumulative reward.

Example: game AI, robotics control, recommendation optimization

Key Terms for Decisions & Ethics Questions

Bias

Systematic errors that hurt certain groups or scenarios.

Fairness

Expectations that models do not unjustly disadvantage groups; definitions vary by context.

Variance

Sensitivity to training data noise. Overfitting = high variance; Underfitting = high bias.

Training vs Inference

Training learns parameters; inference applies the model to new data.

When AI/ML Helps — When It Doesn't

✓
Where AI/ML Adds Value
  • Scale: scoring millions of events faster than manual review.
  • Automation: routing, triage, tagging, summarization, first-line support.
  • Assisted decision-making: recommendations and risk scores with human oversight.
  • Perception tasks: speech-to-text, object detection, document understanding.
✗
When AI/ML May Be Wrong
  • Deterministic guarantees required; probabilistic error cannot be tolerated.
  • Cost exceeds benefit: model lifecycle costs more than the problem's value.
  • Insufficient/untrusted data makes learning unreliable.
  • Regulatory context demands interpretability or audit trails you cannot support.

Fundamentals of GenAI

Core GenAI Concepts

🔢
Tokens

Models process text as subword pieces. Pricing, latency, and context limits are in tokens, not characters.

✂️
Chunking

Splits long documents into segments that fit context windows for retrieval or summarization.

📐
Embeddings

Dense vectors representing text. Similar meanings map to nearby vectors for semantic search.

🔮
Transformers

Architecture enabling large-scale pre-training. Foundation models use transformer backbones.

Advantages vs Disadvantages

✓
GenAI Advantages
  • Adaptability across tasks with prompting and light integration.
  • Rapid prototyping of assistants, summarization, drafting, code help.
  • Developer productivity when used with review and tests.
✗
GenAI Disadvantages & Risks
  • Hallucinations: plausible but false outputs.
  • Nondeterminism: temperature changes outputs run-to-run.
  • Interpretability: hard to audit internal reasoning.
  • Compliance: data handling, IP, and licensing constraints.

Cost Tradeoffs

On-demand vs Provisioned

Token usage for variable traffic vs steady throughput capacity.

Availability vs Cost

Multi-AZ patterns increase resilience but also cost.

Model Size vs Performance

Larger models are more capable but higher latency and price per request.

Customization Approaches

In-context Learning Fastest

Use prompts and examples to steer behavior without changing model weights.

+ Fast to iterate - Token cost; context limits
RAG Moderate

Ground generation on your private documents via retrieval.

+ Better grounding on private docs - Needs solid retrieval and chunking
Fine-tuning Advanced

Specialize model behavior on curated training data.

+ Can specialize behavior - Needs curated data and MLOps discipline
Pre-training Expert

Extremely expensive large-scale training on broad corpora.

+ Maximum control - Rarely relevant except conceptually

Prompt Engineering Techniques

Technique Description
Zero-shot Instruction only, no examples. Model infers task from description.
One-shot / Few-shot Include examples to steer format and reasoning.
Chain-of-Thought Ask model to show intermediate reasoning steps. Improves complex tasks; increases tokens.
Templates Reusable prompts with variables for production consistency.

Guidelines for Responsible AI

Pillars of Responsible AI

⚖️
Fairness & Bias

Systematic skew that disadvantages groups. Mitigate via diverse data, bias testing, and regular audits.

🌍
Inclusivity

Datasets and evaluation cover diverse users and edge cases.

🛡️
Robustness

Stable behavior under noise, typos, and adversarial prompts.

🔒
Safety

Preventing harmful outputs and unsafe recommendations.

🎯
Veracity

Truthfulness and grounding. Related to hallucination risk.

AWS Responsible AI Tools

Bedrock Guardrails

Policy controls on prompts and completions — topic filtering, denied content, sensitive information handling. Configure details to match your requirements.

SageMaker Clarify

Bias and explainability analysis for ML workflows. Detect bias during data prep and model evaluation.

SageMaker Model Monitor

Drift and quality monitoring in production. Alerts when model behavior degrades.

Augmented AI (A2I)

Human review workflows when automation is insufficient. Route low-confidence predictions to humans.

Legal & Reputational Risks in GenAI

⚡

Intellectual property disputes around training data and outputs.

📋

Discriminatory outputs and loss of trust.

🏥

End-user harm from bad advice in sensitive domains.

🎭

Hallucinations presented as facts.

Security, Compliance & Governance

Securing AI Systems on AWS

🔑
Identity & Access

IAM roles with least privilege. Separate data access from model invocation. Avoid long-lived keys where roles suffice.

🔐
Encryption

Data at rest (AWS KMS) and in transit (TLS). Understand key management and rotation patterns for regulated workloads.

🌐
Network Isolation

Amazon VPC, security groups, and PrivateLink patterns reduce exposure to the public internet.

🔍
Data Protection & Discovery

Amazon Macie discovers sensitive data in S3. Combine with classification and access policies.

AI-Specific Threats

CRITICAL
Prompt Injection

Untrusted text in prompts manipulates model behavior — can exfiltrate data or bypass guardrails.

HIGH
Data Exfiltration

Clever prompts or tool misuse in agentic flows can leak sensitive data from retrieval or context.

MODERATE
Poisoning

Manipulation of knowledge sources used in RAG — adversarial content indexed and later retrieved as trusted.

AWS Audit & Compliance Services

CloudTrail

Records who called which AWS API in your account. Essential for security auditing.

Config

Resource configuration history and rules. Track configuration drift over time.

Audit Manager

Automated evidence collection for compliance frameworks.

Artifact

On-demand compliance reports and agreements (SOC, PCI, HIPAA attestations).

Inspector

Workload vulnerability scanning — knows roles in the shared responsibility model.

Trusted Advisor

Cost, security, and fault-tolerance guidance at a high level.
